# Contributing

Thanks for looking. Issues and pull requests are welcome.

Before you send a change, run `npm test` and `npm run typecheck`, and add a test for new logic. Keep the product rules in [docs/DESIGN.md](docs/DESIGN.md) in mind: rank by price per unit only, always show how old a price is, never hide an item that couldn't be priced, never store or log a location, and don't add anything that scrapes a shop's website or app.
